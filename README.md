# NFT generator

Live site: https://coldnightwarmth.github.io/nft/

The complete Drifella library is available: 4,824 collection entries, or 4,251 after deduplication in All mode.

Full-resolution optimized WebP copies power previews. PNG and print exports use original lossless 932×1006 assets hosted on the originals branch. Local folders are supported. Collections are saved in browser storage.

GitHub Pages serves main at the repository root.

## Dratinis

[Open the Dratinis generator](https://coldnightwarmth.github.io/nft/dratinis/).

Layer up to 99 randomly selected images from a 307-image pool, change the background, zoom, regenerate, reorder, and shuffle optional per-layer effects. Right-click Regenerate, Reorder, or Shuffle FX to undo through the shared 10-step history.

Download matching full-resolution PNG and layer/effect JSON files. Star up to 500 generations, recall them from the favorites gallery, or download all favorites as a ZIP with PNGs at the root and matching JSON files in `jsons/`. Favorites persist in browser storage for this site.

Run the Dratinis regression checks with `npm test` (Node.js 18 or later; no dependencies required).
